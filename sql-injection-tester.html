📚Penjelasan SQL Injection

SQL Injection adalah teknik serangan yang memanfaatkan kerentanan dalam aplikasi web untuk menginjeksi kode SQL berbahaya melalui input pengguna. Serangan ini dapat mengakibatkan:

  • 📌 Akses tidak sah ke database
  • 📌 Pencurian data sensitif
  • 📌 Modifikasi atau penghapusan data
  • 📌 Bypass autentikasi
  • 📌 Eksekusi perintah sistem

Tipe-Tipe SQL Injection:

1. Classic SQL Injection

Injeksi langsung ke query SQL

' OR '1'='1

2. UNION-based SQLi

Menggabungkan hasil query

' UNION SELECT NULL--

3. Boolean-based Blind

Menggunakan kondisi TRUE/FALSE

' AND 1=1--

4. Time-based Blind

Menggunakan delay waktu

' OR SLEEP(5)--

5. Error-based SQLi

Memicu error database

' AND 1=CONVERT(int, 'x')--

6. Stacked Queries

Menjalankan multiple queries

'; DROP TABLE users--

Cara Mencegah SQL Injection:

✅ Praktik Keamanan Terbaik

  • Parameterized Queries / Prepared Statements - Selalu gunakan parameter binding
  • Input Validation - Validasi dan sanitasi semua input pengguna
  • Least Privilege - Batasi hak akses database
  • Stored Procedures - Gunakan stored procedures dengan parameter
  • ORM (Object-Relational Mapping) - Gunakan ORM seperti Eloquent, Prisma, dll
  • Web Application Firewall (WAF) - Filter request berbahaya
  • Error Handling - Jangan tampilkan error database ke user
